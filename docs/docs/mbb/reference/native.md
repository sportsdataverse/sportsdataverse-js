# `sdv.mbb` — Native (non-ESPN) APIs

Beyond the ESPN surface, `sdv.mbb` also wraps the league's own live APIs. Same `{ parsed: true }` contract; each method is exposed under both snake_case and camelCase on `sdv.mbb`.

## Native API — KenPom

Flat (non-ESPN) wrappers for kenpom.com (subscription; HTML pages). Host: `https://kenpom.com`. Each method is exposed under BOTH `kenpom_<endpoint>` (snake_case, py/R parity) and `kenpom<Endpoint>` (camelCase canonical) on `sdv.mbb`. Pass `{ parsed: true }` to run the payload through its tidy.js parser; omit it for the raw response. Endpoints marked **multi-table** parse to several frames in sdv-py; with `parsed: true` they return the default shown in the Parser column (one sub-frame, or every table as a dict), and `section: "<name>"` selects any other (an unknown name throws, listing the valid ones). **Auth:** a KenPom subscription login — `email` / `password` on the call, or the `KENPOM_EMAIL` / `KENPOM_PW` environment variables (hoopR's `KP_USER` / `KP_PW` also work). The session is logged in once and reused. The raw response is the page HTML; `{ parsed: true }` returns every table on the page keyed by its HTML id.
